# O'tkazib yuborilgan case'lar

Bu jurnal harness'ni yaxshilash uchun. "Tayyor" deb belgilangandan **keyin**
topilgan har bir muammo shu yerga yoziladi.

Maqsad — aybdor topish emas, teshikni topish. Bir oydan keyin bu jadval
qaysi bosqich zaifligini aniq ko'rsatadi:

- Ko'pi `spec` bo'lsa → `to-spec` da savol yetishmayapti
- Ko'pi `test` bo'lsa → `spec-coverage` yoki `tdd` bo'sh o'tkazyapti
- Ko'pi `review` bo'lsa → `code-review` mezonlari kuchsiz

|---|---|---|---|
| | | spec / test / review / darvoza | |
